# SmartLock

基于 **CH32V30x RISC-V MCU** 的嵌入式智能门锁项目，采用渐进式开发，从最小系统逐步集成 LCD 显示、矩阵键盘、语音提示、指纹识别、RFID 刷卡及 WiFi 远程控制等功能，最终实现一套完整的多模态智能门锁系统。

## 功能特性

- **四种解锁方式** — 6 位数字密码 / AS608 指纹识别 / RFID 刷卡 / 远程 WiFi 开锁
- **OneNET 云平台** — 基于 MQTT 协议，支持远程开关锁、改密码、调音量
- **安全防护** — 连续 3 次错误自动锁定 15 秒，开锁 10 秒后自动关闭
- **密码持久化** — AT24C02 EEPROM 存储，断电不丢失
- **语音交互** — 21 种语音提示，覆盖全部操作场景
- **LCD 实时显示** — 128x128 彩色屏幕，密码掩码显示、状态提示

## 软件设计

### 任务调度

采用时间片轮询的多任务调度架构：

| 任务 | 周期 | 功能 |
|------|------|------|
| `esp8266_proc()` | 2ms | MQTT 消息接收与命令分发 |
| `key_proc()` | 10ms | 矩阵键盘扫描与按键处理 |
| `as608_proc()` | 20ms | 指纹采集、比对与录入 |
| `lock_proc()` | 30ms | 舵机控制与自动关锁计时 |
| `lcd_proc()` | 100ms | LCD 界面刷新与状态显示 |

### 工作模式状态机

```
Mode 0 ─── 主界面（待机）
  │         支持：密码输入 / RFID 刷卡 / 指纹识别 / 远程开锁
  │
  ├── 按键4 ──→ Mode 1 ──→ 验证管理密码 ──→ Mode 2 ──→ 输入新密码并保存
  │                                                      (写入 EEPROM)
  ├── 按键12 ─→ Mode 3 ──→ 验证管理密码 ──→ Mode 4 ──→ 刷卡录入新 IC 卡
  │
  └── 按键8 ──→ Mode 5 ──→ 验证管理密码 ──→ Mode 6 ──→ 采集指纹并存储
                                                        (需采集 2 次)
```

### 安全机制

- **错误锁定** — 连续输入错误密码 3 次，系统锁定 15 秒，禁止一切输入
- **自动关锁** — 开锁后 10 秒未操作，自动关闭并语音提示
- **密码掩码** — LCD 上密码显示为 `******`，防止窥屏
- **管理密码** — 修改密码、录入卡片/指纹前均需验证管理密码

### MQTT 远程控制

通过 OneNET 云平台 MQTT 协议实现远程操作：

| appkey | 功能 | appstring 参数 |
|--------|------|----------------|
| 1 | 远程开锁 | — |
| 2 | 远程关锁 | — |
| 3 | 远程改密码 | 6 位数字密码 |
| 4 | 远程调音量 | 音量值 |

## 开发环境

- **MCU**: CH32V30x (RISC-V)
- **IDE**: MounRiver Studio
- **云平台**: OneNET (中国移动物联网)
- **通信协议**: MQTT (AT 指令通过 ESP8266)
- **编译工具链**: RISC-V GCC

## 快速开始

1. 安装 [MounRiver Studio](http://www.mounriver.com/)
2. 导入 `demo7/` 工程（完整功能版本）
3. 修改 `Driver/esp8266.c` 中的 WiFi 和 MQTT 配置：
   ```c
   // WiFi 名称和密码
   u8 string4[] = "AT+CWJAP=\"你的WiFi\",\"你的密码\"\r\n";
   // OneNET MQTT 认证（替换为你的产品/设备信息）
   u8 string5[] = "AT+MQTTUSERCFG=0,1,\"设备ID\",\"产品ID\",\"token\",0,0,\"\"\r\n";
   ```
4. 编译并烧录到 CH32V30x 开发板
5. 默认密码：`555520`，管理密码（改密指令）：`520951`
